## 🚀 Cómo Usar

Simplemente abrí `index.html` en el navegador. No requiere servidor ni dependencias.

### Navegación
- **Click** en las flechas laterales
- **Swipe** táctil en móvil
- **Drag** con mouse en desktop
- **Teclas** ← → para navegar
- **Doble-click** para dar like ❤️

## 🛠️ Tecnologías

- HTML5 semántico
- CSS3 (gradientes, backdrop-filter, animaciones)
- JavaScript vanilla (sin frameworks)
- Google Fonts (Inter, Outfit)
